1. commit 취소 후 내용 원복 (pull 할때 충돌. 로컬파일을 수정 전 상태로)
--------------------------------------------------------------------------------------------------------------------

git reset HEAD~1 : 마지막 커밋 취소

--add 취소
git restore --staged -- src/main/webapp/lion.yaml : 특정 파일을 staged 에서 제거 (내용은 그대로 둔다) add 취소

--add 취소 및 내용 이전꺼로

git restore -- src/main/webapp/lion.yaml : 특정 파일만 수정 전상태로 (내용까지 바꾼다)
--------------------------------------------------------------------------------------------------------------------


--------------------------------------------------------------------------------------------------------------------
2. 두개의 브랜치 merge (일반적)
--------------------------------------------------------------------------------------------------------------------
1. 첫번째 브랜치를 clean 상태로 한다.(push 까지 완료)

2. 두번째 브랜치로 머지한다.
   git merge origin/두번째브랜치

3. 머치 완료 후 다시 push 한다.
   git push origin 첫번째 브랜치   
--------------------------------------------------------------------------------------------------------------------


--------------------------------------------------------------------------------------------------------------------
3. 강제 overwrite
--------------------------------------------------------------------------------------------------------------------
git fetch origin
git reset --hard origin
git clean -fd

--------------------------------------------------------------------------------------------------------------------
