reset, revert, checkout : 이전버전으로 돌리는 세가지 방법
reset : 시간을 되감는것. 문제가 발생한 이후 커밋들을 모두 없던일로 만든다.
revert : 과거를 청산하는것. 중간것은 유지한채 처리 가능
checkout : 타임머신타고 과거로 돌아가는것

>> reset 특정 시점으로 강제 reset (단 로컬에서만 의미가 있다)
git reset --hard e3adfd2bcf308a9069f52a6e024e1f71d1e218c8 : 뒤에 hash 태그가 없으면, 마지막 상태로 되돌려 진다.
이후 버전이 없어진다.

git revert e3adfd2bcf308a9069f52a6e024e1f71d1e218c8 : 새로운 버전이 생긴다.

git checkout e3adfd2bcf308a9069f52a6e024e1f71d1e218c8
