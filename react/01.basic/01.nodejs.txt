
1. 설치

npx create-react-app blog

2. 브라우져보기

npm start

localhost:3000 으로 본다

3. 폴더구조

> node_modules : 사용하는 라이브러리 들이 있음

> public : 정적파일 보관 html, img 등

이곳에 두면 파일 압축이 되지 않고 그대로 있다.

> src : 소스코드 보관함 css, js 등

> package.json : 설치한 라이브러리 정보듣이 있다. npm 으로 라이브러리 설치할때마다 자동으로 기록이 된다.

데이터를 저장할수 있는 또하나 state  :변경이 되면 html이 자동으로 랜더링이 된다. 새로고침 없이도 된다.
잘 안바뀌는건 let 등 일반변수, 데이터로 활용시는 state 를 사용해서 web app 처럼 작동하게 끔 한다.

  // 변수대신 쓸수있는 데이터 저장 공간
  // 자바스크립트 문법 let [a, b] = [10, 1000];
  let [글제목, 글제목변경] = useState('남자코드 추천'); // [a, b] : a : 첫번째는 내용이 들어간다.(남자코드 추천). b : 두번째는 수정하기 위한 함수
  let [글제목2, 글제목변경2] = useState('남자코드 추천2'); // [a, b] : a : 첫번째는 내용이 들어간다.(남자코드 추천). b : 두번째는 수정하기 위한 함수

  let [글제목어레이, 글제목변경어레이] = useState(['어레이1', '어레이2']); // [a, b] : a : 첫번째는 내용이 들어간다.(남자코드 추천). b : 두번째는 수정하기 위한 함수
