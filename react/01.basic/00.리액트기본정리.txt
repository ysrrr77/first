2. export

export default → 기본으로 내보내기, 가져올 때 {} 없음
export → 이름을 지정해 내보내기, 가져올 때 {} 사용
참고로 이 문법은 React 전용이 아니라 JavaScript 모듈 시스템의 문법이야. React에서는 컴포넌트를 여러 파일로 나눠 관리할 때 자주 사용하는 거지.

구분           export default                  export
내보내기 개수   파일당 기본 내보내기 1개           여러 개 가능
가져오기 문법   import Button                   import { Button }
이름 변경       자유롭게 가능                    as로 변경 가능
주 용도         대표 컴포넌트                    여러 함수나 상수 등


3. JSX란 JavaScript XML의 약자로, JavaScript 코드 안에서 HTML과 비슷한 문법을 사용해 UI(사용자 인터페이스)를 
작성할 수 있도록 해주는 문법 확장입니다. 주로 React에서 웹 화면을 만들 때 사용합니다

> JSX를 사용하는 이유
일반 JavaScript와 JSX를 비교해 보겠습니다.

① 일반 JavaScript

javascript
const element = document.createElement("h1");
element.textContent = "안녕하세요!";

② JSX
jsx
const element = <h1>안녕하세요!</h1>;
JSX를 사용하면 화면의 구조를 직관적으로 작성할 수 있어 코드가 읽기 쉽고 관리하기 편합니다.


4. useState란?
useState는 컴포넌트에서 변하는 값을 저장하고, 그 값이 변경되면 화면을 다시 렌더링하도록 하는 React Hook입니다.

예를 들어 버튼을 누를 때마다 숫자가 증가하는 화면을 만들 수 있어요.

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>숫자: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        증가
      </button>
    </div>
  );
}

3. useState 문법 이해하기

jsx
const [count, setCount] = useState(0);
각 부분의 의미는 다음과 같습니다.

count: 현재 상태값

setCount: 상태값을 변경하는 함수

useState(0): 초기 상태값을 0으로 설정
