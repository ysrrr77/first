방법 1. 탐색기에서 두 파일 비교하기
두개 파일 선택 Compare with Selected

방법 2. 이미 열어 둔 파일 비교하기
첫 번째 파일 탭을 우클릭해서 Select for Compare를 선택해.
두 번째 파일 탭을 우클릭해서 Compare with Selected를 선택해.

단축키

Windows                     
한 줄 삭제                  Ctrl + Shift + K
한 줄 아래에 복사            Shift + Alt + ↓
한 줄 위에 복사              Shift + Alt + ↑
코드 한 줄 위아래로 이동       Alt + ↑ / ↓


다시 실행                   Ctrl + Y
찾기                        Ctrl + F
파일 전체에서 검색              Ctrl + Shift + F
파일 빠르게 열기                Ctrl + P

2. 코드 편집할 때 유용한 단축키


현재 줄 복제                Shift + Alt + ↑ / ↓
현재 줄 위아래로 이동       Alt + ↑ / ↓

여러 줄 한 번에 주석 처리       Ctrl + /
들여쓰기                Tab
들여쓰기 취소           Shift + Tab
여러 줄 동시 편집       Alt + 마우스 클릭
단어 단위로 커서 이동   Ctrl + ← / →
코드 자동 정렬(포맷팅)  Shift + Alt + F


3. 파일과 화면 관리

새 파일 만들기  Ctrl + N

파일 열기       Ctrl + O

파일 탭 전환    Ctrl + Tab

현재 파일 닫기  Ctrl + W

사이드바 열기/닫기  Ctrl + B

터미널 열기/닫기    Ctrl + `

명령 팔레트 열기    Ctrl + Shift + P

화면 확대       Ctrl + +

화면 축소   Ctrl + -

Ctrl + Shift + P는 꼭 기억해 둬! VS Code의 명령어를 검색해서 실행할 수 있어서 단축키를 모를 때도 유용해.

4. 여러 곳을 동시에 수정하기
React 코드를 수정할 때 특히 유용한 기능이야.

Alt + 클릭      여러 커서 만들기

여러 위치를 클릭한 다음 입력하면 해당 위치에 동시에 글자를 입력할 수 있어.
Ctrl + D

같은 단어를 하나씩 선택

예를 들어 App이라는 단어에 커서를 놓고 누르면 다음에 나오는 동일한 단어를 선택할 수 있어. 반복해서 누르면 여러 곳을 선택해 수정할 수 있어.

Ctrl + H

찾아서 바꾸기

현재 파일 안에서 특정 변수명이나 문자열을 다른 이름으로 한꺼번에 변경할 수 있어.
