------------------------------------------------------------------------------------------------------
branch 변경 및 merge 처리

git switch main : main branch 로 변경

>> 각각의 브랜치에서 수정 후 commit 처리한다
>> ex) git switch coopon > 수정 > git add . > git commit -m "coopon에서 수정"
>> ex) git switch main > 수정 > git add . > git commit -m "메인에서 수정"
>> git merge coopon : main 에서 coopon 의 차이점으로 머지
>> 에디터에서 수정 > git add . > git commit -m "수동으로 머지"
>> git push origin merge 로 해경

reset, revert, checkout : 이전버전으로 돌리는 세가지 방법
reset : 시간을 되감는것. 문제가 발생한 이후 커밋들을 모두 없던일로 만든다.
revert : 과거를 청산하는것. 중간것은 유지한채 처리 가능
checkout : 타임머신타고 과거로 돌아가는것
